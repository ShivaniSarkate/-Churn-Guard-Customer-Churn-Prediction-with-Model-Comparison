# 🧪 ChurnGuard – Customer Churn Prediction with Model Comparison

## 🎯 Objective  
Predict customer churn using classification models and compare their performance to recommend the most reliable solution.

## 🧪 Business Context  
A telecom company wants to reduce customer churn. By predicting which users are likely to leave, they can proactively offer retention incentives.

## 🧠 Workflow  
- Simulate customer data  
- Preprocess features  
- Train Logistic Regression and Decision Tree models  
- Evaluate using accuracy, precision, recall, and ROC-AUC  
- Recommend best-performing model

## 📊 Key Insights  
- Logistic Regression offers better precision and ROC-AUC  
- Decision Tree captures more churn cases  
- Recommendation: Use Logistic Regression for retention targeting
